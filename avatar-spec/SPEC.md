## 2. 캔버스 규격

- **모든 파츠 공통: 512 × 768 px** (세로로 긴 전신 치비)
- 파츠는 캔버스 전체 크기로 그려주세요. 파츠가 없는 영역은 **투명**으로!
- 베이스 바디 기준 규격 (`guide_anchors.png` 참조):
  - 얼굴: 가로 106~406, 세로 90~380 (타원)
  - 눈 중심: **y = 262** (face 파츠는 눈 중심을 반드시 여기에!)
  - 어깨선 y = 410 / 허리 y = 520 / 치마 밑단 y = 628
  - 중심선 x = 256 (좌우대칭 기준)

## 3. 파일 형식·명명·저장 위치

- 포맷: **PNG (투명 배경 필수)**
- 명명 규칙:
  - `hair_back_<컨셉>.png` / `hair_front_<컨셉>.png` (예: `hair_back_twintail.png`)
  - `<부위>_<컨셉>.png` (예: `face_wink.png`, `top_hoodie.png`, `hat_ribbon.png`)
  - 컨셉명은 영어 소문자 + 밑줄 (예: `sakura`, `sailor`, `jeans`)
- 저장 위치: `~/workspace/poker/app/client/public/avatars/<부위>/`
  - 예: 헤어 → `avatars/hair/`, 모자 → `avatars/hat/`
- 완성 후 `avatars/parts.json`에 파츠 1줄씩 추가 (id·이름·레어도·가격·파일명)

## 4. 레이어 순서·앵커 포인트

합성 순서 (뒤 → 앞, `guide_layers.png` 참조):

```
1. hair_back (뒷머리 — 맨 뒤)
2. base (베이스 바디)
3. bottom (하의)
4. top (상의)
5. face (얼굴 — 눈·눈썹·입·볼터치)
6. hair_front (앞머리 — 얼굴 위를 덮음)
7. hat (모자)
8. accessory (악세사리 — 맨 앞)
```

- **뒷머리**는 몸통 뒤로 깔려요. 어깨보다 넓게, 턱선(y=380) 아래까지 내려오게 그려주세요
- **앞머리**는 이마를 덮어요 (y=58~208 영역). 눈(y=262)을 가리지 않게!
- **모자**는 앞머리 위에 얹혀요 (헤드밴드는 머리 꼭대기 y=58~90 부근)
- **얼굴 파츠**는 눈 중심 y=262에 정확히 맞춰주세요 (`guide_anchors.png` 빨간 주의 참고)
